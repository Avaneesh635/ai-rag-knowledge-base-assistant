# 📚 AI RAG Knowledge Base Assistant

An AI-powered document question-answering system built using Retrieval-Augmented Generation (RAG), Google Gemini, FAISS, and Sentence Transformers.

The application allows users to upload PDF documents, perform semantic search, retrieve relevant context, and generate accurate answers grounded in the uploaded documents.

---

## 🚀 Features

* PDF Upload and Processing
* Text Extraction from PDFs
* Automatic Text Chunking
* Embedding Generation using Sentence Transformers
* FAISS Vector Database Integration
* Semantic Search
* Retrieval-Augmented Generation (RAG)
* Context-Aware Question Answering
* Google Gemini Integration
* Interactive Streamlit Interface

## ⚙️ Installation

### Clone Repository

git clone https://github.com/YOUR_USERNAME/ai-rag-knowledge-base-assistant.git

cd ai-rag-knowledge-base-assistant

### Create Virtual Environment

python -m venv venv

### Activate Virtual Environment

Windows:

venv\Scripts\activate

### Install Dependencies

pip install -r requirements.txt

---

## 🔑 Environment Variables

Create a `.env` file:

GOOGLE_API_KEY=YOUR_GEMINI_API_KEY

---

## ▶️ Run Application

streamlit run app.py
